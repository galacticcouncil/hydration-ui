# Find an existing Hydration pattern

Snapshot: **2026-10-26**. Start here when building a new element. This guide adds **editorial candidate routes** to the live inventory; it does not certify imports, interactions, resizing, publication status or exact Figma-to-code parity. All IDs and locations below come from the assembled snapshot.

Use the complete component first, then inspect its real variants and nested dependencies. Full keys and exact property suffixes are in the [catalog](catalog/components.json), not copied into this guide. The source library is [Design Library](https://www.figma.com/design/wN5pnsm2FPVoCrxFNEAlYl/?node-id=34-2).

## Fast lookup

Run from this directory:

```bash
python3 scripts/lookup.py search "receiving account"
python3 scripts/lookup.py show 2215:38934 --json
python3 scripts/lookup.py variants 3176:33403 "emphasis=medium size=lg state=rest"
python3 scripts/lookup.py variants 442:28153 "icon=pearlShell"
python3 scripts/lookup.py search "classic/search" --kind component
python3 scripts/lookup.py search "details/separators" --kind variable
python3 scripts/lookup.py pages
```

Use an ID when a name is duplicated. `variants` lists real tuples; a property dropdown does not mean every combination exists. Searches use [routes.json](catalog/routes.json) aliases to find candidates; an exact named definition may still rank ahead of an editorial route.

## Resolve ambiguity before using a family

- **Same name, different source:** `table/sorting` exists on Lists and Input controls; `chipBase` has two definitions on Chips; `transactions/modals` has two sets on Modals & panels; `rpcSelector/desktop` exists on Settings and Misc. Choose the exact ID/path above and inspect it. The catalog does not declare any of these deprecated.
- **Set versus standalone:** `input/transactions/primary` is a component set at `441:18175`, plus a standalone at `3882:29674`. Treat their capabilities separately.
- **Generic names are real names:** preserve values such as `Variant2`, `restSublte`, `changable`, `embeded`, `finalized-sucess`, `Property 1`, and case differences. Inspect children/preview before choosing a vague variant; do not normalize strings when calling Figma.
- **Property suffixes matter:** keep text/boolean/instance-swap keys exactly as exported, including suffixes like `Headline#502:0`. Only `VARIANT` properties use the family’s variant axes.
- **New versus classic illustrations:** `icons/3d` is the set containing the new sunbed, glasses, bank, juicer and pearl assets. A `classic/glasses` standalone is a different vector icon. `icons/3dStates`, `modalStateIcon`, `detailed-icons` and `3diconsSizes` are separate families.
- **Examples are not definitions:** Staking and Basejump have example frames/instances but no local component definitions. Campaigns and the second Misc page also mix examples and design-documentation components. Follow main-component references; do not infer an import key from a frame name.

## Tokens, styles and code

For dark product screens, explicitly select **Themes → Dark**: the source collection default is Light. Select **Misc → Desktop/Mobile** independently. Follow existing bindings: `details/borders` is for component boundaries and `details/separators` for internal dividers. [FOUNDATIONS.md](FOUNDATIONS.md) maps collections, modes and styles; [CODE-MAP.md](CODE-MAP.md) maps implemented controls and Storybook states.

In code, use `@galacticcouncil/ui/components` before composing custom primitives. `EmptyState`, `AssetSelect` and `XcmSummary` are app-level patterns; wallet connection belongs to `@galacticcouncil/web3-connect`. Code Button sizes are `micro | small | medium | large`; Figma `lg/md/sm` values are not code props or guaranteed numeric matches. Typography uses Gazpacho for primary headlines and Geist for secondary/body UI.

The upstream `hydration-styles` token source generates local dark/light token JSON; editing generated values is not a durable token change. See [CODE-MAP.md](CODE-MAP.md) for the exact source/build path.
