# Hydration - new icon library

Current selected icons in one place. Original studies and revisions remain in their existing folders. The selected pearl shell is included and used in the Portfolio Dashboard design in Figma.

- `exports/`: exact current WebP/SVG exports.
- `masters/`: transparent high-resolution PNGs, with original proportions preserved.
- `blender/`: editable saved sources. Shared status source contains the waiting and review scenes.
- `index.html`: visual index with usage and download links.
- `catalog.json`: file map, hashes, scene names and usage.
