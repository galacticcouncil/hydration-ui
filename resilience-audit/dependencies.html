How to read this map

Each path describes the current implementation. Optional services should enrich the UI or disable their own feature; a red path marks a wider dependency that needs isolation. It is not a prediction that every outage crashes the application.

Browser results cover anonymous production routes and a cached reload with healthy Hydration HTTP and WebSocket endpoints. Function tests inject failures into exact installed packages or transpiled source. Source tracing identifies additional paths without proving a browser failure. No signed transaction or live wallet session was tested. Services exposed only by a library are explicitly marked dormant or conditional.
