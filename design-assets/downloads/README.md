# Design download archives

These ZIPs contain design source files and remain versioned here outside the
application public directory. Each exceeds the independent build inventory's
32 MiB per-file limit and must not be copied into the deployment output.

The original public URLs are preserved in `apps/main/public/_redirects` using
immutable repository copies at commit `605b2f59d5e51df113b824d96c88b74ea8e17892`.
The archive contents have not changed.
