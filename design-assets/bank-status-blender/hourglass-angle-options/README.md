# Selected bank A - camera studies

Camera-only studies made from colonnade-options/A-front-back-right.blend. Exact mesh, transform and material signature verified unchanged before every render. Original source SHA256 verified unchanged.

A1 uses the saved hourglass camera quaternion, with a small vertical translation to the bank center. A2 mirrors the low viewpoint. A3 and A4 lift the camera for softer perspectives. All four retain orthographic projection and 5.5 degree roll (A2 mirrored).

Each candidate has an editable .blend and transparent 640px PNG. The contact sheet includes 96px previews and the original hourglass reference. Current runtime assets and original source scenes are untouched.

Reproduce by running Blender background mode on colonnade-options/A-front-back-right.blend with this directory's render_angles.py. hourglass-camera-reference.json records the actual camera read from the canonical status-icons.blend.
