# Bank A4 — upward tilt

The selected A4 angle with a lower eye position matching the upward pitch of the hourglass. A4 azimuth and 5.5 degree roll are preserved. All model geometry, materials and studio lighting remain unchanged. Original A4 source is unmodified.

- bank-a4-upward.blend: editable scene.
- bank-a4-upward-1024.png: 128-sample transparent Cycles render.
- bank-a4-upward-512.webp: preview export, not wired into runtime.
- manifest.json: camera and source/geometry preservation checks.
- render_upward.py: repeatable renderer, using hourglass-angle-options/A4-soft-right.blend as input.
